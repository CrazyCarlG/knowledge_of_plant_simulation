## User Interface Objects

### Display and User Interface Objects

Plant Simulation provides display objects to show the results of the simulation runs and user interface objects prompting input from the user of the simulation model.

You can use the following objects:

| Object | Purpose |
| --- | --- |
| **Button** | Shows a button in the Frame. When you click the button, it executes the action which you programmed in a control. |
| **Chart** | Presents current data and results of the simulation run. |
| **Checkbox** | Toggles between the states on and off, for toggling operating modes, etc. |
| **Comment** | Shows explanatory notes which you added to your simulation model. |
| **CostAnalyzer** | Analyzes costs that the individual machines and the Worker cause. |
| **Dialog** | Designs a dialog box for an object which is similar to the built-in dialog boxes. |
| **Display** | Presents current data and results of the simulation run. |
| **DropDownList** | Shows a drop-down list in the Frame. When you select one of the items, it executes the action which you programmed in the control. |
| **GanttChart** | Shows the chronological sequence of activities as bars on the time axis. |
| **HtmlReport** | Presents current data and results of the simulation run in a report that you can share with co-workers and customers. |
| **SankeyDiagram** | Visualizes the Sankey flows of parts as well as Sankey flows of Workers, who walk freely within the area or walk on FootPaths. |

## Comment

`Comment` [object]

Use the object **Comment** for showing explanatory notes which you added to your simulation model.

### Description

A comment helps you and your colleagues to better understand the intentions behind your model and how it is supposed to work.

You can access it like you do any other object, but be aware that the Comment usually is not involved in the simulation itself. Select **Options > Show Comments** on the View ribbon tab of the Frame, or click the corresponding toolbar icon, to display all Comment objects that you inserted into that Frame. Plant Simulation displays the text in the Frame window which you entered under **Display > Text**.
