# User Interface Objects（用户界面对象）目录总结

本目录是 Plant Simulation 帮助文档中 **User Interface Objects** 对象类的分类目录，包含以下对象类型，每个对象类型下均按 general / methods / attributes / read-only-attributes 等分页并以 `README.md` 总结。

## 对象一览

| 对象 | 说明 |
|---|---|
| `Button` | 按钮（Button） |
| `Chart` | 图表（Chart） |
| `Checkbox` | 复选框（Checkbox） |
| `Comment` | 注释（Comment） |
| `CostAnalyzer` | 成本分析器（CostAnalyzer） |
| `Dialog` | 对话框（Dialog） |
| `Display` | 显示（Display） |
| `Display and User Interface Objects` | 显示与用户界面对象（Display and User Interface Objects） |
| `DropDownList` | 下拉列表（DropDownList） |
| `GanttChart` | 甘特图（GanttChart） |
| `HtmlReport` | HTML 报告（HtmlReport） |
| `SankeyDiagram` | 桑基图（SankeyDiagram） |

## 目录说明

- 每个对象子目录内含对应的 `.md` 源文件（部分含 `.txtx` 文本提取文件）与 `README.md` 总结。
- 本 README 为分类索引，具体内容见各对象子目录。
