# Properties of Lists and Tables（列表与表格的属性）目录总结

本目录是 Plant Simulation 帮助文档中 **Properties of Lists and Tables** 对象的分类目录，包含以下子页面，每个子页面均有独立的 `README.md` 总结。

## 子目录一览

| 子目录 | 内容 |
|---|---|
| `general` | 概述（General） |
| `methods` | 方法（Methods） |
| `attributes` | 属性（Attributes） |
| `read-only-attributes` | 只读属性（Read-Only Attributes） |
| `window` | 窗口（Window） |
| `accessing-range-of-cells` | 用方法访问单元格区域（Accessing a Range of Cells with a Method） |
| `creating-lists-within-lists-and-tables` | 在列表与表格中创建嵌套列表（Creating Lists within Lists and Tables） |
| `methodsAttributes of Cells` | 单元格的方法与属性（Methods / Attributes of Cells） |
| `methods Indirectly Accessing` | 间接访问列表与表格的方法（Methods for Indirectly Accessing Lists and Tables） |

## 目录说明

- 每个子目录内含对应的 `.md` 源文件（部分含 `.txtx` 文本提取文件）与 `README.md` 总结。
- 本 README 为对象索引，具体内容见各子目录。
