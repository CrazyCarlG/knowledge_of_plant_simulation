# Method Attributes

The `Method` object provides the attributes listed below, plus the *Attributes of All Objects*.

> **Note:** You can only access attributes of the `Method` object that refer to the object itself via the reference operator `&`. Without the `&` operator, the attribute is applied to the *contents* of the Method.
>
> To view all methods, read-only attributes, and attributes of an object, open the window **Show Attributes and Methods**. To access the Method, use the reference operator or the anonymous identifier `self`.

---

## NumInExecution [SimTalk]

Returns how often the Method designated by the reference operator `<&>` is being executed at the moment.

- **Type:** Read-only attribute
- **Syntax:** `<&>Method.NumInExecution → integer`
- **Return Value:** The return value has the data type `integer`.

```simtalk
print &MyMethod.NumInExecution
```

---

## Program [SimTalk]

Designates the source code which is passed to the Method designated by the reference operator `<&>`.

- **Remarks:** The assigned source code is executed when the Method is called the next time.
- **Type:** Attribute
- **Syntax:** `<&>Method.Program:string`
- **Assignment Value:** You can assign a value of data type `string`.

```simtalk
&MyMethod.Program := "->real return 0.0"
self.Program := "->real return 0.0"
// next call with the changed instructions

var bInherit:boolean // checks if the attribute 'Programm' is activated or not
getAttribute("Program", bInherit)
print bInherit
```

## RandomSeed [SimTalk] — Method/User-defined Attribute

Sets the random number stream of the Method designated by the reference operator `<&>` or of the user-defined attribute of data type `Method` or `RandTime`.

- **Type:** Attribute
- **Syntax:** `<&>Method.RandomSeed:integer`
- **Assignment Value:** You can assign a value of data type `integer`.

```simtalk
&Method1.RandomSeed := 1313
DataTable.RandomSeed := 101
```

### Remarks

Plant Simulation automatically assigns a random number seed value when inserting an object, so each object has its own random number seed value. When calling a distribution function in a Method, the first parameter (which specifies the random number stream) is optional; if omitted, the random number stream of the Method (or of the user-defined attribute of type Method) is used.

This affects the following distribution functions:
`z_beta`, `z_binomial`, `z_cEmp`, `dEmp`, `z_emp`, `z_erlang`, `z_frechet`, `z_gamma`, `z_geom`, `z_gumbel`, `z_hypgeom`, `z_laplace`, `z_logistic`, `z_logLogistic`, `z_lognorm`, `z_negexp`, `z_normal`, `z_paraLogistic`, `z_pareto`, `z_poisson`, `z_triangle`, `z_uniform`, and `z_weibull`.

You can still call distribution functions with the random number stream parameter as in previous versions. Formulas always require it, since formulas never use the random number stream of the surrounding object.

The random number sequences generated by Method random number streams differ from those of the global random number streams (set under **File > Options > Random Number Seed Values**), even if they share the same seed value.

Plant Simulation keeps a common seed value in the object. It automatically assigns a random number value when inserting an object, but only if the object can create random numbers (e.g. a Station for its Processing Time, or when the object has a user-defined attribute of type `Method` or `RandTime`). Otherwise, the value `0` is assigned to `RandomSeed`. If `RandomSeed` is `0`, the attribute is not shown in **Show Attributes and Methods** and is not written to the model folder. Creating a user-defined attribute of type `Method` or `RandTime` for such an object causes a random number value to be assigned automatically as well.

## UsingNewSyntax [SimTalk]

Activates (`true`) SimTalk 2.0 syntax for the Method designated by the reference operator `<&>` or deactivates it (`false`).

- **Type:** Attribute
- **Syntax:** `<&>Method.UsingNewSyntax:boolean`
- **Assignment Value:** You can assign a value of data type `boolean`.

```simtalk
&Method1.UsingNewSyntax := true
```

### Remarks

- Clicking to convert an existing Method whose source code was created in SimTalk 1.0 notation automatically converts that source code to correct SimTalk 2.0 notation.
- If `UsingNewSyntax` is active, source code must be entered in the improved, abbreviated SimTalk 2.0 notation.
- To use SimTalk 2.0 syntax for all new Methods, activate `UsingNewSyntax` in the Method class in the Class Library.
- Plant Simulation writes the `UsingNewSyntax` setting to the model file.
- If `UsingNewSyntax` is deactivated, source code must be entered using SimTalk 1.0 notation.

## PythonModule

Use the object `PythonModule` for utilizing Python code in a Plant Simulation model with full access to the Plant Simulation object model from within the Python code.

### Requirements

Using Python requires an installation of CPython. The official Python distribution from https://www.python.org/ is recommended (or a Python version installed via Anaconda). Plant Simulation supports Python versions 3.12, 3.13, and 3.14.

If you are using multiple Python environments, specify the path to the Python DLL with the SimTalk function `setPythonDLLPath`:

```simtalk
setPythonDLLPath(dllpath:string)
```

For example:

```simtalk
setPythonDLLPath("C:\Program Files\Python312\python312.dll")
```
