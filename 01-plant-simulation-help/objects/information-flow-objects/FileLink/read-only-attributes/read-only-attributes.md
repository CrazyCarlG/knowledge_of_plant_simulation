# Read-Only Attributes of the FileLink

## Viewing Read-Only Attributes

- Select **Show Attributes and Methods** on the context menu of the **Class Library** to show the methods, read-only attributes, and attributes of the selected **Class**.
- Press the **F8** key or click **Show Attributes and Methods** on the **Home** ribbon tab of the **Frame** into which you inserted an instance to show the methods, read-only attributes, and attributes of the selected **Instance**.

## Querying a Read-Only Attribute

To query the value of a read-only attribute, you might, for example, type:

```
print MyFileLink.UUID
```

## Attributes of the FileLink

The FileLink provides:

- The attributes listed in the table of contents.
- The **Attributes of All Objects**.
