# Information Flow Objects（信息流对象）目录总结

本目录是 Plant Simulation 帮助文档中 **Information Flow Objects** 对象类的分类目录，包含以下对象类型，每个对象类型下均按 general / methods / attributes / read-only-attributes 等分页并以 `README.md` 总结。

## 对象一览

| 对象 | 说明 |
|---|---|
| `AttributeExplorer` | 属性浏览器（AttributeExplorer） |
| `DataList` | 数据列表（DataList） |
| `DataQueue` | 数据队列（DataQueue） |
| `DataStack` | 数据栈（DataStack） |
| `DataTable` | 数据表（DataTable） |
| `FileInterface` | 文件接口（FileInterface） |
| `FileLink` | 文件链接（FileLink） |
| `Generator` | 生成器（Generator） |
| `Method` | 方法（Method） |
| `Properties of Lists and Tables` | 列表与表格的属性（Properties of Lists and Tables） |
| `PythonModule` | Python 模块（PythonModule） |
| `TimeSequence` | 时间序列（TimeSequence） |
| `Trigger` | 触发器（Trigger） |
| `Variable` | 变量（Variable） |
| `XMLInterface` | XML 接口（XMLInterface） |

## 目录说明

- 每个对象子目录内含对应的 `.md` 源文件（部分含 `.txtx` 文本提取文件）与 `README.md` 总结。
- 本 README 为分类索引，具体内容见各对象子目录。
