# TimeSequence — Read-Only Attributes

本目录汇总了 **TimeSequence** 对象的**只读属性（Read-Only Attributes）**说明，内容来源于 `read-only-attributes.md` 与 `read-only-attributes.txtx`。

## 概述

要查看对象的全部方法、只读属性和属性，请打开 **Show Attributes and Methods**（显示属性与方法）窗口。

- 在**类库（Class Library）**的上下文菜单中选择 **Show Attributes and Methods**，可查看所选**类（Class）**的方法、只读属性与属性（一般性说明）。
- 在已插入实例的 Frame 上按 **F8** 键，或点击 Home 功能区选项卡上的 **Show Attributes and Methods**，可查看所选**实例（Instance）**的方法、只读属性与属性（一般性说明）。

## 查询只读属性

查询某个只读属性的值时，例如可输入：

```simtalk
print MyTimeSequence.Full
```

## TimeSequence 的属性

TimeSequence 提供：

- 左侧目录（table of contents）中列出的属性。
- **列表与表格（Lists and Tables）** 的属性。
- **所有对象（All Objects）** 的属性。
