# Material Flow Fundamentals（物料流基础）目录总结

| 子目录 | 内容 |
|---|---|
| `processing-setup-failures-buffers-inventory` | 加工、设置、故障、缓冲与库存（Processing, Set-up, Failures, Buffers, Inventory） |
| `pull-systems-carriers-line-balancing` | 拉式系统、载具与线平衡（Pull Systems, Carriers, and Line Balancing） |
| `sources-routing-transfer-logic` | 源、路由与传输逻辑（Sources, Routing, and Transfer Logic） |
