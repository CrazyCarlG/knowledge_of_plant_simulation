# 用 DataFit 为仿真准备数据（分布拟合）

> 返回：Model a Battery-powered Transporter, Extended

## 概述

仿真研究的目的之一是优化现有或规划中生产工厂的资源（机器、工人、车辆等）可用性，也就是减少机器的故障次数和停机时间。机器一旦发生故障就必须维修，这会导致生产延误并产生成本。

平均故障间隔时间（MTBF）与平均修复时间（MTTR）通常是随机分布的。根据系统的定性特征可以知道分布的类型，但分布的**参数**才是需要确定的。

可用性定义为：

```
Availability = MTBF / (MTBF + MTTR) × 100%
```

当三个值（可用性 AV、MTTR、MTBF）中已知两个时，即可求出第三个。**DataFit Wizard** 会计算 MTTR 和 MTBF 的分布参数，以达到你期望的可用性。

> **注意：** DataFit 对象是在 Frame 中使用对象 Dialog 建模的，因此采用 Windows 设计风格，而非 Siemens PLM 标准设计风格。

**参见：** Compare Statistics Tools

---

## Step 1：定义任务与目标

首先要定义仿真研究的任务与目标，注意不要预先限定你期望或希望得到的某个解。

需要回答的问题：

- 可以预期的吞吐量和产出是多少？
- 资源（机器、工人、工具）的最优数量是多少？
- 工厂中哪些位置需要缓冲区？最优缓冲区大小是多少？
- 工件载具（work piece carrier）的最优数量是多少？
- 哪种控制策略最适合该任务？
- 上述因素如何交互并产生不同结果？

随后确定仿真的范围：

- 是否只需仿真生产工厂？
- 还是也需要仿真其他环节，如供应商来料接收、仓储、发运等？

---

## Step 2：收集与准备数据

收集和准备数据是最重要的任务之一，约占项目时间的 **35%**：

- 建立模型：25%
- 验证与修正：15%
- 运行实验：10%
- 分析与评估：15%

### 使用的数据类型

**静态数据：**

- 从生产计划中提取的数据（通过观察机器获得，或来自车间专家）。
- 从工厂结构中提取的数据。
- 来自班次模型（shift model）的数据。

**随机数据：**

- 故障行为。
- 加工时间和准备/设置时间。
- 废品数量。

### 互联生产/装配设施物料流仿真所需的数据

**1. 覆盖整个生产系统的数据（模型数据）：**

- 生产计划（生产的产品、批量大小等）。
- 工厂布局、结构、控制，以及零件进入/离开系统的位置。
- 返工（返工时间、产生废品的工位、废品频率）。

**2. 覆盖人员的数据（对象数据）：**

- 工人数量及其资质。
- 所工作的班次。
- 移动距离与所需时间。

**3. 覆盖机器、运输系统与工作站的数据（对象数据）：**

- 故障，包括 MTBF、MTTR、基准时间、分布和方差。
- 节拍时间、容量与节拍方差。
- 设置时间。
- 物料供应。

---

## Step 3：决定使用哪种分布

收集好数据后，需要做出一系列决定：

- 为加工时间、设置时间、恢复时间、节拍时间和故障时间分别选择哪种分布。
- 为所选分布输入哪些参数。

为此提供了统计向导（Statistics Wizards），你可以：

- 使用 DataFit 练习分布拟合。
- 使用带边界的分布。

**参见：** Compare Model Random Processes

## 用 DataFit 进行分布拟合

对于**无边界**的分布使用 **DataFit** 对象。

操作步骤：

- 输入一个随机数的观测样本和一个**显著性水平（Level of significance）**。
- 向导随后求出所选分布的参数。

向导会估计所选分布的参数，并在 **Fit** 选项卡上对过滤后的数据执行**拟合优度检验（goodness-of-fit test）**。

> **注意：** 显著性水平是指：一个虽然适用于该样本、但参数被估计的分布，被拟合优度检验拒绝的概率。

**比较示例模型：** 点击 Window 功能区选项卡，点击 Start Page > Getting Started > Example Models > Small Examples。然后在 Examples Collection 对话框中选择相应的 Category、Topic 和 Example，点击 Open Model。

**参见：** Compare Statistics Tools

---

## 在 DataFit 中输入数据

> **注意：** DataFit 只对**超过 10 个值**的样本计算分布参数。

只有在当前选项卡上选择所需设置并输入数据后，才能进入下一个选项卡。DataFit 会随后激活下一个选项卡上的按钮和/或文本框。大多数按钮是用于开启/关闭某项功能的切换按钮。

### 导入待拟合的数据（Input 选项卡）

- 将数据（车间观测到的样本数据，或上一次仿真运行的结果）导入 Plant Simulation 表文件的一列中。然后将该表拖到 Frame 中的 DataFit 对象上并放下。
- 在打开的对话框中选择包含数据的列，点击 **Load**。

或者：

- 点击 **Read**，从你在 **Data file** 文本框中输入的文件名所指定的文件导入数据。
- 从其他程序（如 Excel）导入时，需要在 Plant Simulation 中选择与另一应用相同的**小数分隔符**。也可以通过 Windows 剪贴板将样本数据粘贴到表中（点击 **Open** 打开输入表）。

### 选择数据类型

- **离散数（Discrete numbers）**——大于等于 0 的任意整数（0, 1, 2, 3, ...）。
- **连续数（Continuous numbers）**——包括负数和浮点数（如 -10, 1.4, 5, ...）。

输入完所有必需数据或选择完所需设置后，进入 **Filter** 选项卡。

---

## 在 DataFit 中过滤数据

在 **Filter** 选项卡上过滤数据。过滤有三个目的：

1. 截去非典型数据。
2. 消除离群值（将这些值从样本中移除）。
3. 将数据变换到某个范围（平移或缩放数据）。

过滤数据的步骤：

- 可以（但不必）为 **Lower bound（下界）** 和 **Upper bound（上界）** 输入值。
- 点击 **Start** 开始过滤数据。
- 这会激活 **Show descriptive statistics（显示描述性统计）** 和 **Open filtered data（打开过滤后数据）** 按钮。
  - 点击 **Show** 打开一张显示样本数据特征描述性统计的表。
  - 点击 **Open filtered data** 打开一张用于数据拟合的排序后数据表（即消除不需要的值之后的数据）。

完成后进入 **Fit** 选项卡。

---

## 在 DataFit 中拟合数据

在 **Fit** 选项卡上，DataFit 估计所选分布的参数，并对过滤后的数据执行拟合优度检验。

- 点击 **Select**，在打开的对话框中选择一个、多个或全部分布。
- 输入**显著性水平（Level of significance）**（0 到 1 之间的数；多数情况下为 0 到 0.2 之间）。
- 点击 **Fit**，用样本估计所选分布的参数。
- 对于大样本，使用**卡方检验（Chi-Square Test）**作为拟合优度检验，并输入**类数（Number of classes）**。拟合优度检验描述分布及其参数与给定样本的吻合程度。
- 点击 **Show** 在图表中显示样本的直方图。

完成后进入 **Evaluation** 选项卡。

---

## 在 DataFit 中评估数据

在 **Evaluation** 选项卡上对过滤后的数据进行分析。

选择 DataFit 对拟合检验的排序方式：

- **卡方检验（Chi-Square test）**——适用于所有情况。它将样本数据划分为若干类。样本必须有**超过 40 个值**。
- **Kolmogorov-Smirnov** 和 **Anderson-Darling** 检验——仅适用于 **10 到 2000 个值**的连续分布。

打开结果表，查看在 Plant Simulation 中应输入哪个分布的哪些参数：

- **Result Chi**、**Result KS**、**Result AD** 列说明这些分布是否适用于样本值。当相应值的统计量小于相应的临界值时即适用。评估自然会考虑显著性水平。
- **Parameter 1**、**Parameter 2**、**Parameter 3** 列显示精确数字以及四舍五入后参数的名称，供你输入到 Plant Simulation 对象的对话框中。
- 点击 **Show** 显示参数和拟合优度检验的 Report。
- 点击 **Delete** 减小可能因 Report 而膨胀的模型体积。
- 当所选分布都无法充分表示样本时，可在 Plant Simulation 中使用**经验分布（empirical distribution）**来建模数据。点击 **Open** 打开频率表（Frequency table）。

## 使用带边界的分布

仿真中使用的分布，其取值可能任意大或任意小。使用带上下边界的分布来截去你不想考虑的取值。

> **注意：** 使用带边界的分布会改变均值和标准差。

当使用正态分布对随机时间建模时，下界自动为 0。

示例：为正态分布输入参数 **µ = 2.0** 和 **σ = 1** 时，带下界 0 和上界 3 的分布的实际均值将为 **1.77**。

对于带边界的分布使用 **TruncDistribution** 对象：

- 选择一个分布以及两个边界。
