## 内容摘要

`material-flow.md` 是物料流建模的**主题总览页**，除了一节具体操作说明外，主要通过链接索引引导用户进入各项建模子任务。

### 1. 在列表或表中查找任意值（Find Any Value within a List or Table）

可以在插入仿真模型的 **列表（List）** 或 **表（Table）** 类型对象中查找任意文本或数值。操作步骤如下：

1. 从左侧下拉列表中选择 **Table**。
2. 在搜索范围内输入列表或表中包含的任意文本或数值。
3. 重复 *Find the Name of an Object*（查找对象名称）中所述的第 4 至第 7 步。
4. 单击 **Find**。

> 该操作隶属于 *Find Objects and Text in Your Simulation Model*（在仿真模型中查找对象与文本）。
