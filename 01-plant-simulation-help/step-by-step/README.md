# Step-by-Step（分步教程）目录总结

本目录是 Plant Simulation 帮助文档中 **Step-by-Step** 相关内容的分类目录，包含以下子主题，每个子主题均有独立的 `README.md` 总结。

## 子目录一览

| 子目录 | 内容 |
|---|---|
| `3-d-scene-object-foundations` | 3D 场景对象基础（导航/相机/网格控制、放置/变换/框架编辑） |
| `advanced-material-flow-behavior` | 高级物料流行为（控制/传感器/观察器/距离控制、随机分布） |
| `assembly-robots-conveyance-patterns` | 装配、机器人与传送模式（Converter/Turntable 路由、拆装流程、PickAndPlace 机器人场景） |
| `core-model-construction-workflow` | 核心模型构建工作流（类/库/工具箱、Frame 建模/仿真控制/拖放、物料流建模） |
| `data-integration-parameterization` | 数据集成与参数化（对话框属性浏览器、导入导出/数据库/外部媒体、列表/表格/网络套接字交换） |
| `fluids-energy-workforce-shift-logic` | 流体、能源、劳动力与班次逻辑（日历/封锁区、成本/能耗分析、自由流动物料、工人建模） |
| `graphics-animation-authoring` | 图形与动画创作（构建仿真对象、动画路径/MU/关节/姿态、状态可视化） |
| `material-flow-fundamentals` | 物料流基础（加工/设置/故障/缓冲/库存、拉式系统/载具/线平衡、源/路由/传输逻辑） |
| `onboarding-plant-simulation` | 入门引导（用户界面与基本操作、建模、分步帮助） |
| `realism-media-omniverse-output` | 真实感、媒体与 Omniverse 输出（真实场景构建/图形优化、模型优化/视频录制/Omniverse 输出） |
| `runtime-animation-statistics-interaction` | 运行时动画、统计与交互（图表/报告/可视化分析、图标行为、交互控件/状态切换/动作） |
| `transport-systems-experimentation` | 传输系统与实验（传送带/轨道/AGV/电池、DataFit 分布拟合、实验管理器/遗传优化、模型打包与共享） |

## 目录说明

- 每个子目录内含对应的 `.md` 源文件（部分含 `.txtx` 文本提取文件）与 `README.md` 总结。
- 本 README 为分类索引，具体内容见各子目录。
