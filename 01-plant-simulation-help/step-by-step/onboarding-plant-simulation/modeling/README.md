## 内容摘要

`modeling.md` 介绍仿真的理论基础、Plant Simulation 的事件驱动机制，以及开始建模前需要掌握的关键概念和项目流程。

### 1. 仿真与建模概念
- 仿真与运筹学结合，用于辅助定性与定量决策。
- 仿真能给出复杂问题的良好方案，但**不会自动求得真正的最优解**。
- 当过程过于复杂、无法用数学或优化方法求解时，仿真尤为重要。
- 仿真的目标是通过动态分析得出客观决策，从而降低成本和风险。

### 2. 什么是仿真
- 依据 VDI 3633 标准，仿真是"对系统及其动态过程在可实验模型中的模拟"，其结果可迁移到真实工厂。
- 典型仿真研究五步：检查真实工厂 → 抽象建模 → 运行实验 → 解释数据 → 决策。

### 3. 时间驱动与事件驱动仿真
- Plant Simulation 是**离散、事件驱动**的仿真程序，只关注模型中发生事件的时间点。
- 事件示例：零件进入/离开工位、移动到下一台机器。
- 零件进入物流对象时，程序计算其离开时间，并将"离开事件"插入 **EventController** 的调度事件列表。
- 因此仿真时间在事件之间跳跃推进。

### 4. 为什么要使用仿真
用于**规划新工厂**或**优化现有工厂**，例如：
- 新工厂规划：发现并消除问题、确定节拍/产量、缓冲大小、机器数量、故障影响、人员需求、控制策略、评估多方案、最小化投资。
- 现有工厂优化：验证改进措施、优化控制策略、优化订单顺序、测试日常流程。
- 落地实践：开发控制策略模板、测试暖机阶段场景、培训操作员。
- 综合收益：提高生产率、降低投资、减少库存与节拍时间、优化系统尺寸、降低风险、最大化资源利用。

### 5. 实施仿真项目
仿真模型开发是**循环演化**的过程。实施工作流包括：
- **描述项目**：明确目标与要回答的问题，并书面记录。
- **规划项目**：制定模型概念（初值、模型项、变量、逻辑、实验描述），确定参数、数据与解释方法，列出功能单元并派生应用对象，定义物料流与信息流接口。
- **确定并获取所需数据**：尽早确保实验数据可得，并明确数据获取负责人。
- **构建仿真模型**：从最简单版本开始，逐个构建并测试应用对象，再组装整体模型，并清晰记录文档。
- **验证模型与有效性**：逐对象、组合、整体测试，确保参数正确；再确认功能与真实/计划工厂一致、结果可信，并与生产/规划专家讨论。
- **执行仿真实验并收集结果**：运行实验并采集输出结果。
