# Step-by-Step Help

Introduces the most common modeling tasks. It shows how to proceed when you create your simulation model and how to use the built-in objects to solve your tasks. The detailed instructions help you to quickly learn a procedure.

## Topics Covered

The step-by-step help covers these topics:

- Getting to Know Plant Simulation
- Modeling the Material Flow
- Visualizing the Material Flow
- Animate the Simulation Model and View the Results
- Import Data for the Simulation
- Set Parameters in the Model
