# No Longer Supported SimTalk Names of the 2D Visualization

Previous versions of Plant Simulation provided SimTalk attributes, SimTalk read-only attributes and SimTalk methods referring to the 2D visualization, which we do not support any more.

The command **Find Outdated Functions** on the tab **Debugger** finds all outdated functions in your model and shows them in a window. Plant Simulation shows outdated functions in the source code in a highlighted color.
